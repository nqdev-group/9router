# cli/

Standalone npm CLI package (`9router` on npm) that installs/starts the 9Router server, manages the system tray, and drives the interactive terminal UI. Own `package.json`, version, build, and publish flow — separate from the root Next.js app's package.json.

## Directory map

- `cli.js` — bin entry (`bin.9router`). Arg parsing (`--port`, `--host`, `--tray`, `--skip-update`, `--log`, `xai video`), update check against npm registry, kills stale processes (by port + PID files for the app/MITM/tunnel), spawns the vendored server as a child process, restart-on-crash loop (`MAX_RESTARTS=2`, disables `mitmEnabled` in the DB after repeated crashes), and the Web/Terminal/Hide-to-tray/Exit interface menu loop.
- `hooks/postinstall.js` — npm `postinstall` hook; warms SQLite + tray runtime deps. Non-fatal on failure (retried at `cli.js` startup).
- `hooks/sqliteRuntime.js` — installs `better-sqlite3`/`sql.js` into `~/.9router/runtime/node_modules` (user-writable, avoids Windows EBUSY on `npm i -g` updates). Exports `ensureSqliteRuntime`, `buildEnvWithRuntime` (sets `NODE_PATH` for the spawned server).
- `hooks/trayRuntime.js` — installs `systray2` into the same runtime dir, macOS/Linux only (Windows skipped — see Conventions). Evicts the legacy `systray` package, chmods the Go tray binary +x.
- `src/cli/tray/` — `tray.js` (dispatch to Windows vs Unix tray, `killTray()` with graceful shutdown), `trayWin.js` (spawns `tray.ps1` via PowerShell, JSON-lines protocol over stdin/stdout), `tray.ps1` (NotifyIcon script), `icon.ico`/`icon.png`, `autostart.js` (per-OS: macOS `launchd` plist, Windows Startup `.vbs`, Linux `~/.config/autostart/*.desktop`).
- `src/cli/terminalUI.js` — interactive TUI entry, renders cached header (endpoint/tunnel/API key), routes to `src/cli/menus/*`.
- `src/cli/menus/` — one file per TUI screen: `providers.js`, `apiKeys.js`, `combos.js`, `settings.js`, `cliTools.js`.
- `src/cli/utils/` — `input.js` (selectMenu/pause), `display.js`, `endpoint.js` (tunnel-aware URL resolution), `format.js`, `clipboard.js`, `menuHelper.js`, `modelSelector.js`.
- `src/cli/api/client.js` — HTTP client to the local server; authenticates with `x-9r-cli-token`, derived from the shared machine-id file + `~/.9router/auth/cli-secret`.
- `src/cli/commands/xaiVideo.js` — `9router xai video` subcommand (POST `/v1/videos/generations`, poll, download mp4). Bypasses the launcher/self-heal flow entirely — assumes a gateway is already running.
- `scripts/build-cli.js` — builds this package's `app/` (see below).
- `scripts/buildMitm.js` — esbuild-bundles root `src/mitm/server.js` (no externals) into `cli/app/src/mitm/server.js`, self-contained so it can be copied to `DATA_DIR/runtime/` and spawned from there.
- `app/` — **gitignored** (`.gitignore`: `app/*`), generated by `npm run build`. Not source; see relation to root below.

## Relation to the root app

`cli/` does not depend on the root package at the npm-dependency level — it **vendors a full built copy of it**. `scripts/build-cli.js` runs `npm run build` in the root dir (`NEXT_TRACING_ROOT_MODE=workspace`, custom `NEXT_DIST_DIR`), then copies the Next.js standalone output, `custom-server.js`, static/public assets, vendor-chunks, and the complete server tree into `cli/app/`. It asserts `app/api/v1/chat/completions/route.js` and `app/api/v1/messages/route.js` exist post-copy (`build-cli.js:133-149`) as a build-correctness guard. `sql.js` and `open` are force-copied into `cli/app/node_modules` (Next's tracing sometimes misses them); `better-sqlite3` is stripped (installed at runtime instead, see Pitfalls).

**Version sync**: `build-cli.js` Step 0 overwrites the root `package.json`'s `"version"` to match `cli/package.json`'s version before every build (`build-cli.js:158-169`) — so despite root `AGENTS.md` describing them as "versioned independently," running the CLI build mutates the root version field as a side effect.

## Conventions

- Native/optional deps (`better-sqlite3`, `systray2`) are never bundled in the npm tarball — they're lazy-installed into `~/.9router/runtime/node_modules` (`%APPDATA%\9router\runtime` on Windows) by `hooks/*Runtime.js`, both at `postinstall` and again defensively at every `cli.js` startup.
- Windows tray = PowerShell `NotifyIcon` script, zero binaries — deliberate, to avoid AV (e.g. Kaspersky) flagging unsigned Go tray binaries. macOS/Linux use the `systray2` fork (legacy `systray@1.0.5`'s 2017 binary fails modern macOS/Apple Silicon dyld).
- Process kill-matching is a whitelist, never a bare substring match on `"9router"` — must be `node` + `9router` + (`cli.js` or an app path segment), or `next-server` (`cli.js:276-307`), to avoid killing editors/greps that merely mention the name.
- `.npmignore` is a strict allowlist (`* ` then un-ignore `cli.js`, `hooks/`, `app/`, `package.json`, `README.md`, `LICENSE`) — new source dirs (e.g. `src/`, `scripts/`) are excluded from the published tarball unless also added to `package.json` `files`.

## Dev / build / publish

```bash
cd cli
npm run dev          # nodemon --watch cli.js,src,hooks
npm run build        # node scripts/build-cli.js — builds root Next app, vendors into cli/app/
npm run pack:cli      # build + npm pack --pack-destination ../..
npm run publish:cli   # build + npm publish
```
`postinstall` and `prepublishOnly` also invoke these hooks automatically.

## Pitfalls

| Pitfall | Where |
|---|---|
| `cli.js` hard-exits ("Standalone build not found") if `app/` wasn't built — it's gitignored, not present on fresh checkout | `cli.js:527-539` |
| `npm run build` in `cli/` silently rewrites root `package.json` version | `scripts/build-cli.js:158-169` |
| First run needs network to install `better-sqlite3`/`systray2` into `~/.9router/runtime`; failure is non-fatal but falls back to `sql.js` / no tray | `hooks/sqliteRuntime.js`, `hooks/trayRuntime.js` |
| macOS "hide to tray" keeps the *same* process alive instead of spawning a detached child — a detached child on macOS sits outside the login session and `NSStatusItem` silently fails to register | `cli.js:770-783` |
| Unix `killTray()` must await graceful IPC exit of the systray2 Go binary before respawning, else a duplicate/ghost tray icon persists until logout | `src/cli/tray/tray.js:247-298` |
| After 2 crash-restarts, `cli.js` force-disables `mitmEnabled` in the DB even if MITM wasn't the cause | `cli.js:592-597,833-852` |
| `9router xai video` (and future subcommands) skip all self-heal/launcher logic — assumes a gateway is already running | `src/cli/commands/xaiVideo.js` |
