# .claude/agents/

Local scratch space for custom Claude Code subagent definitions (`*.md` with frontmatter — see Claude Code docs for the format). Nothing is committed from here: root `.gitignore` ignores all of `.claude/` in this repo (it's treated as local-only working files, alongside `.claude/skills/`), so anything placed here stays on your machine only.

For guidance that should actually reach every contributor/agent, use `AGENTS.md` (root or per-directory) instead — see the root `AGENTS.md` pointer list.
